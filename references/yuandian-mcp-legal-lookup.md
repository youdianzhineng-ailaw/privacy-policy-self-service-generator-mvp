# 元典 MCP 法律法规检索要求

用于 MVP 复查报告中需要确认法律法规、监管规则、国家标准或具体条文依据的场景。该能力服务于依据核验，不把 MVP 隐私协议变成法条汇编。

## 使用时机

在复查报告阶段出现以下情况时，优先使用元典 MCP 检索：

- 需要确认某项要求对应的法律法规、部门规章、监管规则、国家标准或指南名称；
- 需要确认条文编号、实施状态、效力层级、发布机关或适用范围；
- 需要判断某个处理方式错误提醒是否有明确法律依据、监管规则参考或国家标准参考；
- 用户明确要求说明“法律依据”“法规依据”“第几条”“是否现行有效”；
- 产品涉及敏感个人信息、未成年人、跨境传输、自动化决策、个性化推荐、AI 训练、重要数据、关键信息基础设施或高监管行业，且已有依据不够确定。

普通 MVP 正文起草不强制逐条检索。只有复查报告需要引用、核验或解释依据时才调用。

## MCP 配置参考

如当前环境已配置元典 MCP，可使用其检索法律法规。配置地址：[https://open.chineselaw.com/mcp-config](https://open.chineselaw.com/mcp-config)。

配置示例：

```json
{
  "mcpServers": {
    "yuandian-mcp-server": {
      "type": "stdio",
      "command": "npx",
      "args": [
        "-y",
        "yuandian-mcp-server"
      ],
      "env": {
        "YUANDIAN_API_KEY": "使用实际密钥或环境变量注入"
      }
    }
  }
}
```

不得在 skill 文件或输出文档中写入真实 API Key。

## 检索输出要求

复查报告中涉及检索的事项，应记录：

| 检索事项 | 检索工具 | 核验对象 | 核验结果 | 适用说明 | 进一步核验 |
| --- | --- | --- | --- | --- | --- |
| 例如：定位广告推送 SDK 的告知依据 | 元典 MCP | 文件名称、条款编号、效力层级 | 已核验或未核验 | 与本产品处理活动的关系 | 是或否 |

核验结果应尽量写清：

- 文件名称；
- 条文编号或章节；
- 依据层级：法律、行政法规、部门规章、规范性文件、国家标准、指南、平台规则或监管实践；
- 发布机关、实施状态或版本信息；
- 与产品具体处理活动的对应关系；
- 检索时间或“本次复查时点”。

## 不可用时的处理

当前环境没有元典 MCP、API Key 不可用、检索失败、结果冲突或无法确认效力时：

- 在复查报告中写明“元典 MCP 未配置、不可用或本次未完成检索”；
- 对该依据标记“需进一步核验”；
- 不编造条文编号、发布机关、实施状态或具体法律结论；
- 可基于一般合规判断提出风险提示，但必须说明依据未完成核验。

## 引用边界

- 只引用与本产品处理活动直接相关的依据，不机械罗列全部法条。
- 能确认的，写清文件名称和条款编号；不能确认的，保持“需进一步核验”。
- 不长篇复制法律法规原文，优先做短句概括，并说明其与具体产品事实的关系。
- 元典 MCP 检索结果用于辅助复查，不替代律师、数据合规顾问或企业内部法务的正式审查。
